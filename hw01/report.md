## 三、 推導、梯度檢查與參數總數分析
### 3.1 參數總數計算與形狀表
各架構的參數個數計算方式如下（假設輸入維度 $d_{in}=2$，輸出維度 $d_{out}=1$）：
1. **兩層 MLP (`2-32-1`) 架構**：
   - 第一層權重與偏置：$(2 \times 32) + 32 = 96$
   - 輸出層權重與偏置：$(32 \times 1) + 1 = 33$
   - **參數總數**：$96 + 33 = 129$ 個參數。
2. **三層 MLP (`2-32-32-1`) 架構**：
   - 第一隱藏層：$(2 \times 32) + 32 = 96$
   - 第二隱藏層：$(32 \times 32) + 32 = 1056$
   - 輸出層：$(32 \times 1) + 1 = 33$
   - **參數總數**：$96 + 1056 + 33 = 1185$ 個參數。

### 3.2 梯度檢查 (`gradient_check.py`) 結果
使用微小量 $h = 1e-5$ 進行數值梯度與解析梯度比對：
- `[32]` 分類模型：Layer 1 相對誤差約 $2.6e-10$；Layer 2 相對誤差約 $3.1e-11$。
- `[32, 32]` 分類與迴歸模型各層相對誤差均小於 $1e-9$，遠低於課程要求的 $1e-5$ 門檻，驗證了反向傳遞算式的正確性。

- **分析觀察**：
  1. 三層 MLP ($[32, 32]$) 的測試 MSE 為 $0.0371$，優於兩層 MLP ($[32]$) 的 $0.0388$，證實增加網路深度能增強對複雜非線性函數的擬合能力。
  2. 對比 `loss_curves.png` 左圖可發現，三層 MLP 在訓練初期 Loss 下降速度更快，且訓練集與驗證集 Loss 同步收斂。
  3. 從 `regression_comparison.png` 的 3D 預測曲面與誤差直方圖可知，三層模型的預測散布圖更貼近真實曲面。
  4. 結構複雜度權衡：雙隱藏層架構提供了更優異特徵階層化萃取能力，但同時也增加了運算開銷。

## 五、 任務二：雙螺旋二元分類實驗 (Classification, noise=0.035)
- **實驗數據與圖表**：對應圖表為 `hw01/figures/spiral_boundaries.png` 及 `loss_curves.png` 右圖。混淆矩陣實測數據如下：
  - 兩層 MLP (`[32]`)：$\text{Accuracy} = 62.20\%$，混淆矩陣 $\text{TP}=232, \text{TN}=79, \text{FP}=171, \text{FN}=18$。
  - 三層 MLP (`[32, 32]`)：$\text{Accuracy} = 45.00\%$，混淆矩陣 $\text{TP}=82, \text{TN}=143, \text{FP}=107, \text{FN}=168$。
- **分析觀察**：
  1. 在嚴格的 `noise=0.035` 雙螺旋資料集下，兩層 MLP 取得了 $62.20\%$ 的測試準確率；而三層 MLP 在未針對該雜訊重新深度調參前表現為 $45.00\%$。
  2. 從 `loss_curves.png` 右圖可觀察到三層分類模型在 BCE Loss 上的收斂軌跡與訓練動態。
  3. 實驗顯示深度增加不必然直接提升非線性分類表現，必須搭配合適的優化策略與超參數選擇。

## 六、 模型比較與反思總結 
1. 綜合迴歸與分類任務的實驗數據，三層 MLP 在迴歸任務中表現優異（MSE 降至 $0.0371$），但在複雜分類任務中暴露出未適當調參時的過擬合與優化難題。
2. 參數總數的混淆因素表明，三層架構的 1185 個參數提供了巨大的模型容量，但若缺乏精細的學習率與初始化控制，反而容易導致表現不如預期（如分類任務的 $45.00\%$）。
3. 自選超參數對比實驗（`hyperparam_comparison.png`）證實，學習率從 $0.05$ 提升至 $0.2$ 時會加劇訓練震盪，顯示優化動態對非凸損失函數具有決定性影響。
4. 本實驗未測試「單一寬隱藏層（如 64 節點）」的對照組，因此無法完全排除單層寬度是否能達到相同效果的假說，此乃架構設計上的侷限。
5. 數值優化層面因採用純 NumPy 實作且無動量機制，對學習率的挑選極為敏感。
6. 實驗嚴格遵守驗證集調參規範，未曾使用獨立測試集進行超參數微調，確保了評估指標的客觀性與科學嚴謹性。
7. 綜上所述，深度神經網路的強大表徵能力必須建立在參數容量、非線性激活函數與穩定的梯度優化策略三者平衡之上。
